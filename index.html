Project 01 ★ Featured

Irish Rental Market
Intelligence Dashboard

SQL Python Power BI Web Scraping Daft.ie Data

Scraped 5,000+ live rental listings from Daft.ie using Python, structured them into a SQL database, then built an interactive Power BI dashboard tracking rent trends across Dublin, Cork and Galway. Includes county-level filtering, bedroom type breakdowns and YoY change analysis — packaged as a business-ready investment report.

Key insight: South Dublin commuter belt 3-bed rents rose ~12% YoY, while Cork city remained 18% below Dublin — a clear opportunity signal for a hypothetical property investment firm.
